# safe — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer une app Flutter Android + Linux où l'utilisateur stocke des paires clef/valeur dans un coffre chiffré par un mot de passe maître.

**Architecture:** Un fichier coffre unique, chiffré en bloc (XChaCha20-Poly1305) avec une clé dérivée du mot de passe maître (Argon2id). La crypto est pure et sans IO, le stockage ignore la crypto, l'interface ne voit que `VaultSession`. Toute modification ré-écrit le coffre entier de façon atomique.

**Tech Stack:** Flutter 3.44.6 / Dart 3.12.2, `sodium` 4.0.4 (FFI + native assets, variante *sumo* pour Argon2id), `path_provider`, `file_selector`, `share_plus`.

**Spec:** `docs/superpowers/specs/2026-08-14-safe-design.md`

## Global Constraints

- Dépendance crypto: `sodium: ^4.0.4` avec `package:sodium/sodium_sumo.dart` et `SodiumSumoInit.init()`. **Pas** `sodium_libs` (déprécié en 4.x). Argon2id n'existe que dans la variante sumo.
- Argon2id: `opsLimit = 3`, `memLimit = 128 * 1024 * 1024`, `alg: CryptoPwhashAlgorithm.argon2id13`, sel de `sodium.crypto.pwhash.saltBytes` octets.
- AEAD: `sodium.crypto.aeadXChaCha20Poly1305IETF`, clé de `keyBytes` (32) octets, nonce de `nonceBytes` (24) octets tiré via `sodium.randombytes.buf`.
- Magic du fichier: `SAFEVLT1` (8 octets ASCII), version 1, `kdf_id` 1, entiers little-endian, en-tête de 62 octets utilisé comme `additionalData`.
- Aucun secret en clair sur disque. Écriture: `.tmp` → `fsync` → `.bak` → `rename`.
- Tout le code sensible est testé par `flutter test`; `flutter analyze` doit rester sans avertissement.
- Langue de l'interface: français.

### Task 3: Couche cryptographique

**Files:**
- Create: `lib/crypto/vault_crypto.dart`

**Interfaces:**
- Consumes: `Vault` (Task 2)
- Produces:
  - `class KdfParams { final int opsLimit; final int memLimit; static const KdfParams defaults = KdfParams(opsLimit: 3, memLimit: 128 * 1024 * 1024); }`
  - `class VaultCrypto { VaultCrypto(this._sodium); }` avec `SodiumSumo` injecté (testable, aucune IO)
  - `SecureKey deriveKey(String password, Uint8List salt, KdfParams params)`
  - `Uint8List seal(Vault vault, SecureKey key, Uint8List salt, KdfParams params)` → fichier complet, en-tête inclus (nonce tiré à chaque appel)
  - `Uint8List sealWithPassword(Vault vault, String password, {KdfParams params = KdfParams.defaults})` — dérive une clé sur un sel neuf, scelle, libère la clé
  - `Vault open(Uint8List fileBytes, String password)` — lève `WrongPasswordException` si le tag est invalide, `FormatException` si magic/version cassés
  - `Uint8List newSalt()`
  - `class WrongPasswordException implements Exception {}`

- [ ] **Step 1: Écrire les tests qui échouent**

```dart

late VaultCrypto crypto;
setUpAll(() => sodium = SodiumSumoInit.init());
setUp(() => crypto = VaultCrypto(sodium));

test('aller-retour avec le bon mot de passe', () {
  final vault = Vault([VaultEntry.now(key: 'a', value: 'secret')]);
  final bytes = crypto.sealWithPassword(vault, 'hunter2');
  expect(crypto.open(bytes, 'hunter2').entries.single.value, 'secret');
});

test('mauvais mot de passe rejeté', () {
  final bytes = crypto.sealWithPassword(const Vault([]), 'hunter2');
  expect(() => crypto.open(bytes, 'hunter3'), throwsA(isA<WrongPasswordException>()));
});

test('en-tête falsifié rejeté', () {
  final bytes = crypto.sealWithPassword(const Vault([]), 'hunter2');

  expect(() => crypto.open(bytes, 'hunter2'), throwsA(isA<WrongPasswordException>()));
});

test('magic invalide rejeté', () {
  final bytes = crypto.sealWithPassword(const Vault([]), 'hunter2');
  bytes[0] = 0x00;
  expect(() => crypto.open(bytes, 'hunter2'), throwsFormatException);
});

test('fichier tronqué rejeté', () {
  final bytes = crypto.sealWithPassword(const Vault([]), 'hunter2');
  expect(() => crypto.open(bytes.sublist(0, 40), 'hunter2'), throwsFormatException);
});

test('nonce différent à chaque scellement', () {
  final a = crypto.sealWithPassword(const Vault([]), 'hunter2');
  final b = crypto.sealWithPassword(const Vault([]), 'hunter2');
  expect(a.sublist(38, 62), isNot(b.sublist(38, 62)));
});

test('la valeur en clair n_apparaît pas dans le fichier', () {
  final vault = Vault([VaultEntry.now(key: 'gmail', value: 'TRESOR')]);
  final bytes = crypto.sealWithPassword(vault, 'hunter2');
  expect(String.fromCharCodes(bytes).contains('TRESOR'), isFalse);
  expect(String.fromCharCodes(bytes).contains('gmail'), isFalse);
});
```

- [ ] **Step 3: Implémenter la crypto**

En-tête (62 octets, little-endian): magic 8, version 1, kdf_id 1, opsLimit u32, memLimit u64, sel 16, nonce 24. `seal` construit l'en-tête, puis `aeadXChaCha20Poly1305IETF.encrypt(message: vault.toBytes(), nonce: nonce, key: key, additionalData: header)` et concatène. `open` relit les paramètres depuis l'en-tête, redérive la clé, déchiffre avec le même `additionalData`; toute `SodiumException` devient `WrongPasswordException`. Toujours `key.dispose()` dans un `finally`.

- [ ] **Step 3: Implémenter la session**

## Notes d'exécution

- Les tests de crypto initialisent libsodium une seule fois par fichier (`setUpAll`) — la dérivation Argon2id à 128 Mio coûte quelques centaines de millisecondes.
- Les tests de widgets ne doivent jamais dériver une vraie clé Argon2id à chaque `pumpWidget`: utiliser une `VaultSession` déjà déverrouillée, construite une fois.
- `flutter test` honore les build hooks de `sodium` (libsodium est compilée à la première exécution, ce qui rend le premier lancement lent).
